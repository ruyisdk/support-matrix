# CoM260 Kit

## Overview

CoM260 Kit is a development kit based on the SpacemiT K3 platform. The tested configuration has 16GB RAM and 128GB storage. Refer to the [K3-CoM260 datasheet](https://github.com/spacemit-com/docs-product/blob/main/zh/k3_com260/com260_ds.md) for hardware information.

## Technical specifications

- **CPU**: SpacemiT K3
- **CPU cores**: 8 × X100 + 8 × A100
- **RAM**: 16GB LPDDR5
- **Storage**: 128GB UFS
- **Power supply (chassis rating)**: DC 19V / 2.37A or 12V / 5A
