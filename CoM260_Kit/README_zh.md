# CoM260 Kit

## 概述

CoM260 Kit 是基于 SpacemiT K3 平台的开发套件，本次测试配置为 16GB 内存 / 128GB 存储，硬件信息参考 [K3-CoM260 数据手册](https://github.com/spacemit-com/docs-product/blob/main/zh/k3_com260/com260_ds.md)。

## 技术规格
- **CPU**: SpacemiT K3
- **CPU 核心**: 8 × X100 + 8 × A100
- **RAM**: 16GB LPDDR5
- **存储**: 128GB UFS
- **电源（机身标注）**: DC 19V / 2.37A 或 12V / 5A
