# SpacemiT K3 Pico-ITX

SpacemiT K3 Pico-ITX 是一款基于 SpacemiT K3 SoC 的紧凑型 RISC-V 单板计算机，集成 8 个 X100 通用计算核心和 8 个 A100 AI 核心，提供 16 GB、32 GB 两种 LPDDR5 内存配置。开发板支持 UFS 本地存储、NVMe 扩展、千兆以太网、万兆 SFP+、Wi-Fi 6、蓝牙 5.2、显示、摄像头及工业扩展接口，适用于边缘 AI 和嵌入式应用开发。
