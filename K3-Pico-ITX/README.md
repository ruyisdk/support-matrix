# SpacemiT K3 Pico-ITX

The SpacemiT K3 Pico-ITX is a compact RISC-V single-board computer based on the SpacemiT K3 SoC. It integrates eight X100 general-purpose cores and eight A100 AI cores, and is available with 16 GB or 32 GB of LPDDR5 memory. The board provides UFS storage, NVMe expansion, Gigabit Ethernet, 10 Gigabit SFP+, Wi-Fi 6, Bluetooth 5.2, display, camera, and industrial expansion interfaces for edge AI and embedded application development.
